# AICMS — AI Content Management System

Файловая CMS с встроенным AI-ассистентом и редактором Lumina.

## Возможности

### 📝 Контент
- **Lumina Editor** — WYSIWYG-редактор с блоками, таблицами, изображениями, видео, AI
- **Страницы и новости** — мультиязычность, черновики, запланированная публикация, версионирование
- **Виджет-зоны** — модульная компоновка шаблонов

### 🎨 Внешний вид
- **17 тем** оформления (helios, sity, parallax, editorial, minimal, tech и др.)
- **Конструктор тем** — 3 макета × 6 цветовых схем × 5 шрифтов = 90 комбинаций
- **Тёмная тема** админки с полной поддержкой контрастности

### 🧩 Модули (26 шт.)
- **Контентные**: hero, gallery, faq, team, testimonials, pricing, stats, accordion, tabs, video_gallery, parallax, countdown_timer, social_links, cta_banner, features_grid, progress, newsletter
- **Интерактивные**: contact_form, contact_info, comments, booking (отель), cafe, shop, forum, auth_block
- **Пример**: example_module (шаблон для разработчиков)

### 🤖 AI
- **Текст**: OpenRouter, DeepSeek, Groq, Z.ai — 8 шаблонов промптов
- **Изображения**: Pollinations (бесплатно), Z.ai, Stability AI, OpenRouter (DALL-E 3)
- **Видео**: Z.ai (CogVideoX), Stability Video
- **Дополнительно**: AI SEO мета-теги, AI перевод страниц на 6 языков

### 🛒 Минимагазин
- Каталог товаров с категориями, изображениями, галереей
- Корзина, оформление заказа, купоны (процент/фикс.)
- **Управление складом**: движение товаров, инвентаризация, low-stock alerts
- **Отзывы** с модерацией и рейтингами
- Доставка с расчётом по весу
- Платёжные системы: YooKassa, Stripe
- CSV импорт/экспорт

### 🏨 Бронирование (отель)
- Категории номеров и комнаты с фото, ценами, удобствами
- **Проверка пересечений дат** — нельзя забронировать занятый номер
- Автоматический расчёт ночей
- Управление заявками: new / confirmed / done / cancelled

### 🍽 Кафе
- Столики с вместимостью и расположением
- **Проверка занятости столика** на выбранное время
- Управление заявками

### 💬 Комментарии
- Древовидные ответы
- Рейтинги (звёзды)
- Модерация: pending / approved / spam / deleted
- Лайки/дизлайки (новое)
- Редактирование в течение 5 минут (новое)

### 📝 Форум
- Категории, темы, ответы
- BBCode, поиск, пагинация
- Закрепление/закрытие тем
- Подписки на темы (новое)
- Отметка "Решено" для Q&A (новое)

### 👥 Роли пользователей
- **admin** — полный доступ
- **moderator** — форум + комментарии
- **seller** — магазин
- **user** — обычный пользователь

### 🔒 Безопасность
- CSRF-токены на всех формах
- Honeypot + time-trap на публичных формах
- Rate limiting (login, API, формы)
- CSP headers с report-uri
- Admin IP allowlist
- Trusted proxies configuration
- 2FA (TOTP) с backup codes
- Session fixation protection
- Secure cookies (HTTPS)
- Maintenance Mode (config + файловый kill-switch)
- Audit log всех действий

### 🔧 Система
- Файловое хранение (JSON) или MySQL/SQLite (опционально)
- Кэширование HTML-страниц
- Корзина для страниц и новостей
- Версионирование страниц (до 10 версий)
- Бэкапы (ручные и автоматические)
- REST API с Bearer-токеном
- Webhooks + Telegram-бот

## Установка

### Требования
- PHP 7.4+ (рекомендуется 8.0+)
- Расширения: json, session, mbstring (обязательно)
- Опционально: PDO (MySQL/SQLite), curl, gd, zip

### Быстрая установка
1. Распакуйте архив в корень веб-сервера
2. Откройте `http://ваш-сайт/` — откроется мастер установки
3. Следуйте шагам: язык → проверка сервера → хранилище → настройки → администратор
4. После установки **обязательно смените пароль** в Настройки → Аккаунт

### Ручная установка
1. Создайте `data/config.json`:
```json
{
    "site_title": "Мой сайт",
    "theme": "helios",
    "default_lang": "ru",
    "languages": [{"code":"ru","name":"Русский"}]
}
```
2. Создайте `data/users.json` с bcrypt-хэшем пароля:
```json
{
    "username": "admin",
    "password": "$2y$10$..."
}
```
3. Создайте `data/content/ru/pages.json` — `[]` (пустой массив)
4. Откройте сайт — должно работать

### Настройка AI
1. Получите ключ на https://openrouter.ai/keys (бесплатно)
2. Откройте `data/.env.php` и впишите ключ в `OPENROUTER_API_KEY`
3. В админке: Настройки → AI → выберите провайдер и модель

### Подключение базы данных (опционально)
Требуется для магазина, форума, комментариев, бронирования.
1. В админке: Настройки → База данных
2. Выберите MySQL или SQLite
3. Введите реквизиты (MySQL) или путь (SQLite)
4. Нажмите "Сохранить" — таблицы создадутся автоматически

## Безопасность в production

1. **Смените пароль admin** сразу после установки
2. **Включите 2FA** в Настройки → Аккаунт
3. **Удалите `install.php`** после установки (если手动 установлен)
4. **Настройте HTTPS** — Let's Encrypt или Cloudflare
5. **Укажите trusted proxies** в Настройки → Безопасность, если сайт за Cloudflare/Nginx
6. **Опционально: admin IP allowlist** — ограничьте доступ к админке по IP
7. **Включите CSP report** на 1-2 недели для сбора нарушений
8. **Регулярные бэкапы** — Настройки → Бэкапы → включите автобэкап
