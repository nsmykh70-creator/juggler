1. УСТАНОВКА
-----------
Вариант A: Через установщик (рекомендуется)
  1. Распакуйте архив в корень веб-сервера
  2. Откройте http://ваш-сайт/install.php в браузере
  3. Следуйте шагам мастера установки:
     - Шаг 1: Выбор языка
     - Шаг 2: Проверка сервера
     - Шаг 3: Выбор хранилища (JSON / MySQL / SQLite)
     - Шаг 4: Настройка сайта (название, тема, язык)
     - Шаг 5: Создание администратора
  4. Удалите install.php после установки

Вариант B: Ручная настройка
  1. Распакуйте архив в корень веб-сервера
  2. Создайте data/config.json:
     {
       "site_title": "Мой сайт",
       "theme": "helios",
       "default_lang": "ru",
       "languages": [{"code":"ru","name":"Русский"}]
     }
  3. Создайте data/users.json с администратором
  4. Создайте data/content/ru/pages.json и news.json
  5. Откройте сайт — должно работать

2. ТРЕБОВАНИЯ К СЕРВЕРУ
----------------------
  - PHP 7.4+ (рекомендуется 8.0+)
  - Расширения: json, session, mbstring (обязательно)
  - Опционально: PDO (MySQL/SQLite), curl, gd, zip
  - Веб-сервер: Apache (с mod_rewrite), Nginx, или встроенный PHP

3. БАЗА ДАННЫХ (опционально)
---------------------------
AICMS работает на JSON-файлах по умолчанию. Для модулей
(комментарии, форум, магазин) нужна MySQL или SQLite:

  MySQL: укажите в Настройки → База данных
  SQLite: создаст файл data/aicms.db автоматически

6. AI ВОЗМОЖНОСТИ
----------------
  - AI SEO — генерация мета-тегов (в редакторе страниц)
  - AI Перевод — перевод страниц на другие языки
  - AI Генерация — генерация текста, изображений, видео
  - AI в Lumina — встроенный AI-ассистент в редакторе

Настройка: админка → Настройки → AI
  - Провайдер: OpenRouter (бесплатный ключ на openrouter.ai/keys)
  - Модель: mistralai/mistral-7b-instruct:free
  - Также поддерживаются: DeepSeek, Groq, Z.ai

7. РОЛИ ПОЛЬЗОВАТЕЛЕЙ
--------------------
  - admin — суперпользователь (всё)
  - moderator — форум + комментарии
  - seller — магазин
  - user — обычный пользователь

Управление: админка → Пользователи

8. БРОНИРОВАНИЕ (ОТЕЛЬ)
----------------------
  - Категории номеров: Люкс, Стандарт, etc.
  - Номера: фото, цена, вместимость, удобства
  - Форма: заезд, выезд, ночи, выбор номера
  - Управление: админка → Дополнения → Отель

9. КАФЕ
------
  - Столики: название, вместимость, расположение
  - Форма: дата, время, выбор столика, гостей
  - Управление: админка → Дополнения → Кафе

10. ФОРУМ
--------
  - Темы, ответы, категории
  - Редактирование/удаление (автор или модератор)
  - Закрепление/закрытие тем (админ/модератор)
  - Поиск, пагинация, BBCode
  - Управление: админка → Дополнения → Форум

11. УВЕДОМЛЕНИЯ
--------------
Real-time toast-уведомления в админке:
  - 💬 Комментарии на модерации
  - 📅 Бронирования отеля
  - 🍽 Бронирования кафе
  - 🛍 Заказы магазина
  - ✉️ Сообщения с сайта

12. БЕЗОПАСНОСТЬ
---------------
  - .htaccess защищает data/, cache/, logs/
  - CSRF-токены на всех формах
  - Honeypot + time-trap на публичных формах
  - Rate limiting на формы бронирования
  - Security headers (X-Frame-Options, X-Content-Type-Options)
